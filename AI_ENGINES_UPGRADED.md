- `huggingface-mistral-7b` → `huggingface-qwen-2.5-72b`

### Migration Notes
- Existing stored engine preferences will automatically fallback to GPT-4o if the old engine name is no longer valid
- Cache entries with old engine names will still work but won't match new engine selections
- Cost tracking data retains historical model names for accuracy
