# All Engines Working

This file supersedes the earlier Spark/static-hosting instructions. Use [README.md](README.md), [DEPLOYMENT.md](DEPLOYMENT.md), and [VALIDATION.md](VALIDATION.md) for the current implementation and observed verification.

The app requires a Node backend and persistent SQLite storage. Configure server-only keys using `.env.example`. Test fixtures establish software behavior, not live provider access. The existing Drive Fabric is not bound to this app. Audio/video modes produce textual briefs.

If an old credential was committed or included in a browser bundle, revoke it at its provider and configure a replacement privately. Never reuse an exposed key.
